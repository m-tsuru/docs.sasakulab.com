Hugo でテーマからスクラッチする

2025/02/06 16:00

docs.sasakulab.com は Hugo で作られています．

インストール

brew install hugo

サイト作成

hugo new site site-name
cd site-name
git init
hugo server

hugo server で http://localhost:1313 ホストされる．正常に (Page Not Found と言われるから異常に？) ホストされたら準備完了．^Cで抜ける．

テーマ作成

hugo new theme blazing-fast
